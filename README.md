# vpa06-konstsherbakov — генератор PDF-чеков

## Что это

CLI-скрипт на Python: берёт данные чеков из CSV или JSON, подставляет их в HTML-шаблон и генерирует PDF с поддержкой кириллицы. Готовый файл сохраняется в папку output/ и открывается автоматически.

## Установка (Windows)

1. Установить Python 3.10 или новее.
2. Установить GTK3 Runtime — нужен библиотеке WeasyPrint: https://github.com/tschoonj/GTK-for-Windows-Runtime-Environment-Installer/releases (последний .exe, при установке оставить галочку Set up PATH environment variable).
3. Перезапустить терминал.
4. Создать виртуальное окружение: `python -m venv .venv`
5. Активировать его: `.venv\Scripts\Activate.ps1`
6. Установить зависимости: `pip install -r requirements.txt`

На macOS вместо GTK3: `brew install weasyprint`.

## Запуск

`python main.py`

Скрипт покажет список файлов с данными и шаблонов, затем список чеков. Выбор — вводом номера.

## Как проверить

Выбрать invoices.csv, шаблон invoice_classic.html и чек 1002. В папке output/ появится invoice_1002.pdf и откроется автоматически. Итоговая сумма — 5 649,00 ₽, кириллица отображается корректно.

## Структура

- `main.py` — скрипт
- `data/` — тестовые данные (CSV и JSON)
- `templates/` — HTML-шаблоны с плейсхолдерами Jinja2
- `fonts/` — шрифт DejaVu Sans для кириллицы
- `output/` — готовые PDF (не хранится в репозитории)

## Промпт

Скрипт сгенерирован по составному промпту — полный текст в файле `prompt.md`. Инструмент: Claude Code в VS Code (вместо Cursor).
