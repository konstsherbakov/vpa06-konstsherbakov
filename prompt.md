Контекст: учебный проект — генератор PDF-чеков из данных. Windows 11, Python 3.14, виртуальное окружение .venv уже создано, установлены weasyprint, jinja2, pandas. Библиотека GTK3 для WeasyPrint установлена через GTK3 Runtime в C:\Program Files\GTK3-Runtime Win64\bin.

Задача: напиши CLI-скрипт main.py, который:
1. Читает все CSV и JSON файлы из папки data/. CSV — через pandas, JSON — через стандартный модуль json.
2. Читает все HTML-шаблоны из папки templates/.
3. При запуске выводит пронумерованный список файлов с данными и пронумерованный список шаблонов.
4. Через input даёт выбрать один файл данных и один шаблон по номеру.
5. Выводит пронумерованный список чеков (уникальные invoice_id) из выбранного файла.
6. Пользователь выбирает чек — скрипт подставляет данные в шаблон через Jinja2 и генерирует PDF через WeasyPrint в папку output/. Имя файла: invoice_<id>.pdf.
7. После генерации автоматически открывает PDF системной программой: os.startfile на Windows, subprocess с open на macOS.

Структура данных: один чек состоит из нескольких строк-товаров. Поля: invoice_id, date, customer, product, price, qty. В шаблон передавай данные чека, список товаров и посчитанную итоговую сумму (price * qty по каждой строке и общий итог).

Требования:
- На Windows до импорта weasyprint добавь путь C:\Program Files\GTK3-Runtime Win64\bin через os.add_dll_directory, если папка существует.
- Поддержка кириллицы: подключи шрифт DejaVu Sans через @font-face из локальной папки fonts/. Объясни, откуда скачать файл шрифта.
- Работает на Windows и macOS. Пути — через pathlib, относительно папки скрипта.
- Аккуратное меню в консоли. Обработка ошибок: неверный номер, пустая папка, битый файл — понятное сообщение, а не падение.
- Папку output/ создавай автоматически, если её нет.
